# 错误码

统一响应体失败形态：`{ "code": xxxxx, "message": "..." }`（HTTP 状态与码段一致）。

| 码 | HTTP | 语义 | 常见场景 |
| --- | --- | --- | --- |
| `40000` | 400 | 通用请求错误 | 参数非法、连接失败原因透传 |
| `40001` | 400 | 校验失败 | 用户名/密码强度、长度约束、凭据导出未二次确认 |
| `40100` | 401 | 凭据无效 | 用户名或密码错误、管理引导票据无效/过期 |
| `40101` | 401 | 令牌过期/无效 | access_token 过期（刷新后重试）、未登录 |
| `40102` | 401 | 令牌已吊销 | refresh_token 被吊销或轮换 |
| `40300` | 403 | 禁止访问 | 账号禁用、管理权限未授予、scope 不足 |
| `40301` | 403 | 需要 admin 角色 | client 令牌访问管理端点 |
| `40400` | 404 | 资源不存在 | 账号/规则/令牌 ID 不存在、二维码超 10 分钟 |
| `40900` | 409 | 冲突 | 用户名/规则/组名重复 |
| `42900` | 429 | 触发限流 | 登录尝试过频、连续失败锁定（message 含解锁秒数） |
| `50000` | 500 | 内部错误 | 数据库/签发等内部异常 |

## 客户端处理建议

- `40101`：用 refresh_token 调 `/api/v1/auth/refresh` 后原样重试一次；仍 401 回登录页
- `40102`：会话已被吊销，必须重新登录
- `42900`：按 message 中的秒数倒计时后再试，不要立即重试
- 管理引导票据（`40100`）：票据一次性，控制台会话过期请重新从「管理此节点」进入

# anet-gui 图形客户端

anet-gui 是全功能图形客户端（Windows / macOS / Android），三路独立开关让它同时可以是
办公终端、内网转发机与机房留守管理端。

## 界面导览

- **连接**：接入链接一键导入（或剪贴板识别）、本地代理开关（SOCKS5/HTTP 自动识别，仅 127.0.0.1）、手动添加节点、已保存节点管理（连接/断开/导出/删除）
- **节点**：已连接节点实时状态卡片；「可管理」徽标与「管理此节点」入口；可管理上游自动发现
- **路由**：全部节点下发规则的合并视图；逐条暂停/恢复（立即生效并本地记忆）；长表粘性表头 + 折叠搜索
- **设置**：角色与远程面、开机自启、自动代理/自动重连、语言与主题

灵动岛（标题栏中央）实时显示代理状态与网络降级明细；连接成功、异常等事件以弹性通知弹出。

## 三路独立开关（设置 → 角色与远程面）

### 开关A 客户端角色（默认开）

连上游、本地代理、路由组合——现有全部客户端能力。关闭即断开全部节点并停止代理
（纯转发机场景）。所有变更落 `gui.role_toggle` 审计（`~/.anet/gui/gui-audit.jsonl`）。

### 开关B 服务端角色（默认关）

内嵌完整 anet-svc 节点（同一 `NodeServer` 装配根）：relay listener、账号/规则/令牌/审计、SQLite。

- **首开强制设管理密码**（argon2id 落库），随后内嵌节点自动启动
- 默认端口避让本地独立节点与 Docker 演示链（59290）：API `127.0.0.1:59293`、Relay `0.0.0.0:54431`
- 数据目录 `~/.anet/gui/embedded-node/`
- 「打开控制台」在独立窗口管理内嵌节点（复用节点管理 SPA）
- 「扇出」菜单管理内嵌节点的 connector（入库 CRUD + 启停 + 权限组收敛下拉，默认不收敛）；
  接入上游后本机客户端隧道的规则将转售给下游（路由再发布）

### 开关C Web 远程面（默认关）

把本机管理界面经 HTTP 暴露，浏览器访问与坐在本机前同等体验：

- **强制先设管理密码**（argon2id 哈希存 `~/.anet/gui/web-auth.json`）
- 默认仅 `127.0.0.1:59291`；改 LAN 地址为显式操作并记 `web.exposure_change` 审计
- 鉴权与服务端同强度：登录限流（5 次/分钟、连续失败锁 15 分钟）、JWT 12h、登录/导出审计
- 凭据导出在 Web 端需二次确认

## 控制台通道（管理此节点 / 可管理上游）

节点卡片上的管理入口（详见「带内管理面」）：

| 入口 | 前提 | 路径 |
| --- | --- | --- |
| 管理此节点 | 账号被授予管理权限（管理版接入链接） | 本机 → 客户端隧道 → 节点 API |
| 可管理上游 | 上游 relay 令牌暴露控制面 | 本机 → 客户端隧道 → 中继 → 上游 API |

均在独立窗口打开完整管理 SPA，票据自举登录，无需手输密码。

## 凭据与隐私

- 凭据存 `~/.anet/credentials.json`（Unix 0600）；导出接入链接含明文密码，请谨慎分享
- 节点配置离线缓存 `~/.anet/cache/`：断网时沿用旧规则组网，恢复后无缝升级
- 关闭主窗口最小化到系统托盘；托盘菜单可显示窗口、启停代理、退出

## 移动端 (Android)

- `app-*-debug.apk` 为移动端侧载包。
- 移动端系统级状态岛与后台常驻服务（Android 前台服务通知 / iOS Live Activities）架构正在规划演进中，详情参考「开发 → 路线图」。

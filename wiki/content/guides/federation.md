# 联邦：统一签发与端到端加密

联邦模型让「有公网的会合点（B）」「拥有内网资源的资源主（C）」「需要接入的消费者（A）」
三方各保主权：B 只提供可达性，令牌与授权永远属于资源主。消费者接入**无账号层**——
C 直接签发委托令牌，令牌即唯一身份。

## 统一签发的四个维度

管理端扇入/扇出页的「签发」页签 →「签发」，按信任与拓扑选档：

| 维度 | 档位 | 说明 |
| --- | --- | --- |
| 入口 | **直连本端点**（direct） | A 直连 C 自己的 listener：TLS 已端到端，无中继参与，信任档锁明文；自注册进 C 的本地注册表 |
| 入口 | **经扇出会合点**（relay） | 经容灾集合上游代收：令牌逐一注册到所选上游，任一在线上游都可接入；注册随会话存活 |
| 信任 | **明文** | 逐跳 TLS，B 可见流量内容 |
| 信任 | **E2E** | 引用组含端到端加密组：全部 Open 端到端加密直达 C，B 仅见不透明路由词（`en_xxx`） |
| 信任 | **E2E + 授权管理** | 额外下发管理引导票据（经 E2E 通道，绝不明文过中继）：只读 / 规则 / 全权三档 |
| 路由 | **专线**（dedicated） | 委托方整机流量进隧道，规则词表对委托方不可见 |
| 路由 | **分流**（split） | 词表经 E2E 加密下发，委托方仅授权目标进隧道（需 E2E 组） |
| 并发 | **单会话**（single） | 同令牌新会话踢旧留新（容忍重启抖动） |
| 并发 | **多会话**（multi） | 并存上限为签发时的 max_sessions 快照（端点设置 `delegation_max_sessions`，默认 8） |

relay 入口还需选择**容灾集合**（勾选代收的上游）与**主入口**（链接首连地址，其余按序
故障切换）。签发产出完整 `anet://connect` 链接（也可下载 `.anet` 凭据文件，支持 4 位
PIN 加密），令牌明文仅此一次。

**信任含义**：明文档下，容灾集合 = 「让谁看见流量」的集合；E2E 档下，集合仅是
可用性/成本决策（上游只见路由词）。

列表中可查看每个令牌的逐上游注册状态（已注册 / 注册中 / 离线 / 失败原因），
「吊销」即时生效：所有在线上游清除注册并踢出该令牌的活动会话。

## 一键采纳（中继 B 侧）

管理端「权限组」或「规则」页 →「采纳」：按扇入端点分组列出全部上送组，待采纳一键
镜像为本地组（`组名@节点ID`）。采纳组是**只读活镜像**：对端改了规则或 E2E 标记，几秒内
自动跟随；对端离线保留最后快照。要编辑请点「复制」——复制出一份独立的本地组，原镜像
继续跟随。删除采纳组即解除采纳。

路由宣告（advertise）无需手工维护：扇出的上送组规则自动并集进对上游的路由声明
（上送即路由声明）；仅当需要宣告上送组之外的额外网段时才手工填写。

## 端到端加密组（e2e_required）

权限组开启「端到端加密」后：

- 该组**只能**挂到委托令牌（不可挂扇入令牌 / 扇出连接——这些主体没有 E2E 密钥，
  写入口统一拦截）；
- 该组目标的一切访问必须 E2E 直达 C——命中该组的明文 Open 被 C 一律拒绝
  （fail-close：配置降级攻击退化为拒绝服务，绝不退化为明文泄露）；
- **entrust 零泄露路由**：E2E 委托自动携带 `en_<令牌哈希前缀>` 不透明路由词——
  签发**不要求**上送组或路由宣告：B 只见「en_xxx → C」，组名、规则、网段全程无感知。

## 消费者（A 侧）

导入链接（粘贴 / .anet 文件 / anet:// 拉起）即连：

- 委托凭据是纯数据面密钥——无需 API 登录，客户端直接拨主入口 relay；
- 链接内嵌容灾集合与逐入口证书指纹：当前入口断开自动按序切换（在飞连接由应用层重试，
  与一切 VPN 行为一致）；
- 链接带 E2E 路由词时，全部 Open 自动端到端加密（无感）；
- 管理档链接经 E2E 配置通道取引导票据，可直接打开签发端管理控制台（全权档还可穿透
  管理签发端扇出发现的上游：委托方 → E2E → 签发端 → 扇出会话 → 上游）。

## 生命周期与吊销

- relay 入口的委托令牌**随扇出会话存活**：C 离线时令牌在上游自动失效，重连后自动
  重新注册恢复，B 侧零落库；direct 入口注册在 C 本地持久注册表。
- **可选过期与用量上限**：签发时可设过期时间与用量上限（默认不限）；过期或用尽后
  注册同步停止上送（列表显示已过期/已用尽），签发端数据面同步硬拒。扇入令牌同样支持。
- 吊销 = C 删除本地记录 + 向集合内每个在线上游发吊销帧；离线上游随断线天然失效。
- 并发执法：single 档同令牌第二会话踢旧留新；multi 档并存至 max_sessions 上限，超限拒开。
  同一上游的多条扇出连接自动强制 `名称#连接名` 身份后缀，互不挤占。

## 边界（诚实声明）

- 容灾是**重连级**故障切换：不同入口 IP 不同，在飞 TCP 连接必然断开重试，无无缝漫游。
- 无前向安全性：B 录制流量 + 事后令牌泄露 → 历史流量可解（Noise_NK 前向安全握手属
  后续规划）。
- 元数据（连接时间、流量大小、路由词）对 B 可见——本模型目标是主权与可达，不是匿名。
- 委托令牌即信任根：与接入凭据同等保管，泄露立即吊销。

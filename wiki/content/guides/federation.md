# 联邦：签发委托与端到端加密

联邦模型让「有公网的会合点（B）」「拥有内网资源的资源主（C）」「需要接入的消费者（A）」
三方各保主权：B 只提供可达性，账号与授权永远属于资源主。

三种共享方式，按信任档位选择：

| 方式 | 适用 | B 能看见什么 |
| --- | --- | --- |
| 一键采纳（P1） | 信任 B 的管理员：C 上送权限组，B 管理员采纳后开账号给 A | 流量内容（逐跳 TLS） |
| 签发委托（P2，透明档） | C 直接给 A 发凭据，不麻烦 B 管理员 | 流量内容 |
| 签发委托 + E2E 组（P3） | 不信任 B：内容端到端加密 | 仅路由词（hint），不见目标与内容 |

## 一键采纳（中继 B 侧）

管理端「权限组」或「规则」页 →「采纳」：按扇入端点分组列出全部上送组，待采纳一键
镜像为本地组（`组名@节点ID`）。采纳组是**只读活镜像**：对端改了规则或 E2E 标记，几秒内
自动跟随；对端离线保留最后快照。要编辑请点「复制」——复制出一份独立的本地组，原镜像
继续跟随。删除采纳组即解除采纳。

## 签发委托（资源主 C 侧）

管理端「扇出」页 →「签发委托」页签 →「签发委托」：

1. **注册目标（容灾集合）**：勾选代收该令牌的上游（在线且协议 v3+ 的默认全选）。
   令牌逐一注册到所选上游，任一在线上游都可代收接入。
2. **主入口**：链接的首连地址；其余为容灾备援，客户端断开按勾选顺序自动切换。
3. **权限组**：令牌可访问的本地组（多选）。带 `E2E` 徽标的组强制端到端加密。
4. **接入模式**（选中 E2E 组时出现）：**专线**——委托方整机流量进隧道，规则词表对委托方
   不可见，适合专机专线；**分流**——规则词表经 E2E 加密下发，委托方仅授权目标进隧道，
   日常流量不受影响。中继在两档下都只见粗路由词。
5. **授权管理**（可选，需 E2E 组）：委托方获得一张引导票据（经 E2E 通道下发，绝不经过
   中继明文），可直接打开本端点的管理控制台——只读 / 规则 / 全权三档；**全权**档还可
   穿透管理本端点扇出发现的上游（控制台链路：委托方 → E2E → 本端点 → 扇出会话 → 上游），
   中继全程只见路由词。
6. 备注后生成——得到完整链接（也可下载 `.anet` 凭据文件，支持 4 位 PIN 加密）。

路由宣告（advertise）无需手工维护：扇出的上送组规则自动并集进对上游的路由声明
（上送即路由声明），E2E 路由词也从同一集合自动派生——保证词表恒落在对方路由表
实际承载的范围内；仅当需要宣告上送组之外的额外网段时才手工填写。

**信任含义**（签发对话框内固定提示）：透明档下，容灾集合 = 「让谁看见流量」的集合；
E2E 档下，集合仅是可用性/成本决策（上游只见路由词）。

列表中可查看每个令牌的逐上游注册状态（已注册 / 注册中 / 离线 / 失败原因），
「吊销」即时生效：所有在线上游清除注册并踢出该令牌的活动会话。

## 端到端加密组（e2e_required）

权限组开启「端到端加密」后：

- 该组**只能**挂到委托令牌（不可挂本地账号 / 扇入令牌 / 扇出连接——这些主体没有 E2E 密钥，
  四个写入口统一拦截）；
- 该组目标的一切访问必须 E2E 直达 C——命中该组的明文 Open 被 C 一律拒绝
  （fail-close：配置降级攻击退化为拒绝服务，绝不退化为明文泄露）；
- **entrust 零泄露路由（v4+）**：E2E 委托自动携带 `en_<令牌哈希前缀>` 不透明路由词——
  签发**不再要求**上送组或路由宣告：B 只见「en_xxx → C」，组名、规则、网段全程无感知；
  旧端兼容：有效 advertise 非空时另附 legacy 路由词回退（新端优先 en、旧端回退 ehint）。

## 消费者（A 侧）

导入链接（粘贴 / .anet 文件 / anet:// 拉起）即连：

- 委托凭据是纯数据面密钥——无需 API 登录，客户端直接拨主入口 relay；
- 链接内嵌容灾集合与逐入口证书指纹：当前入口断开自动按序切换（在飞连接由应用层重试，
  与一切 VPN 行为一致）；凭据卡片显示「委托」徽标与当前入口；
- 链接带 E2E 路由词时，全部 Open 自动端到端加密（无感）。

## 生命周期与吊销

- 委托令牌**随扇出会话存活**：C 离线时令牌在上游自动失效（C 离线时 A 本就够不到 C 的资源）；
  C 重连后自动重新注册恢复，B 侧零落库。
- **可选过期与用量上限**：签发时可设 `expires_at` / `max_uses`（默认不限）；过期或用尽后
  注册同步停止上送（列表显示已过期/已用尽），签发端数据面同步硬拒。扇入令牌与客户端
  账号（隧道令牌）同样支持可选过期窗。
- 吊销 = C 删除本地记录 + 向集合内每个在线上游发吊销帧；离线上游随断线天然失效。
- 同一节点同一身份的第二会话踢旧留新（容忍重启抖动）；同一上游的多条扇出连接自动
  强制 `名称#连接名` 身份后缀，互不挤占。

## 边界（诚实声明）

- 容灾是**重连级**故障切换：不同入口 IP 不同，在飞 TCP 连接必然断开重试，无无缝漫游。
- v1 无前向安全性：B 录制流量 + 事后令牌泄露 → 历史流量可解（Noise_NK 前向安全握手
  已规划为 P3.5）。
- 元数据（连接时间、流量大小、路由词）对 B 可见——本模型目标是主权与可达，不是匿名。
- 委托令牌即信任根：与接入凭据同等保管，泄露立即吊销。

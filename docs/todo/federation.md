# 联邦模型（Federation）：公网会合点 + 资源主主权 + 信任分级（实施计划）

> 来源：三轮架构讨论（2026-08-04），从「扇出只能 insecure 连」「分享链接是 127.0.0.1」两个实测问题演化而来
> 定位：企业联邦对接（GUI「节点连节点 · 敬请期待」条目）的设计蓝本
> 状态：**P1 已落地**（2026-08-04，实施记录见 `docs/plan/federation.md`，端到端验收测试 `crates/node/tests/federation_test.rs`）；P2/P3 待实施；现有代码的相关地基见 §3

---

## 1. 目标（解决什么问题）

让「**有公网地址的人**」和「**有资源的人**」解耦：

- 今天：公网入口（B）既是会合点又是主权者——消费者账号必须开在 B 上，B 的管理员决定谁能去哪；资源主（C/D）只是 B 的附属，无法直接面向消费者签发。
- 终态：B 只做会合（rendezvous）与转发；资源主直接对消费者**签发、授权、吊销**，并按信任分级选择让 B 看见多少（透明中继 ↔ 只看见路由标签）。

标尺拓扑（全部讨论以此校验）：

```
        A（消费者）
        │ 扇入（一条接入链接）
        ▼
        B（公网入口，唯一有公网地址）◄──── 扇出注册 ────┐
   ┌────┴────┐                                    ┌────┴────┐
   C（数据公司1）+ 内网 anet 集群               D（数据公司2）+ 内网 anet 集群
```

终态下 A 的能力：

1. **C 直接新建账号/令牌分享给 A**（B 的管理员不在场）——今天不能，这是核心差距；
2. A 一条链接吃透全链：C/D 内网及其深层集群，新节点上线广告路由后立即可达，不重发链接；
3. 授权粒度为 C/D 各自的权限组（带来源 tag，命名空间隔离），各自吊销各自生效；
4. 不信任 B 时 C 开 E2E：B 只见「给 C」，不见内容；策略零上送；
5. A 与 C 同内网时，C 可发直连链接，零迂回不绕 B。

## 2. 关键设计决策（讨论已收敛，实施不得偏离）

1. **目标式路由，严禁源路由**：接入链接不编码路径/跳板序列（拓扑泄露、链路变化全失效、环路难查）。
   深内可达由路由表收敛解决（已实现，四级链测试）。链接恒为三件套：**入口地址 + 凭证 + 入口证书指纹**。
2. **无按节点端口分配**：relay 为 mux 单端口，「分配」的单位是节点身份与路由前缀，不是 TCP 端口。
3. **信任分级是两档，非前提**：
   - 透明中继档（默认）：B 可见目标与载荷；C 推送策略、B 代执法。无需新加密。
   - E2E 档（**资源主 C/D 选择**，可按权限组粒度）：客户端与出口节点端到端加密，B 仅见路由标签。
4. **路由粒度与授权粒度分离**：C 可对 B 只广告粗前缀（B 盲转），细规则（如 R1=具体主机）仅存于 C 本地授权——
   由此「C 授权 A 访问 B 不知道的目标」仅在 **E2E 档 + 粗广告** 或 **直连链接** 下成立；
   透明档经 B 路径时，未广告/未推送的目标 A 拿不到（advertise 即资源主的边界声明）。
5. **主权 = 签发权与执法权留在资源主**：不是「不要账号」（按人授权必须有身份），而是签发委托——
   C 签发的 psk_ 能力令牌，B 的 listener 代为验证（签名验证 / 转发验证）；psk_ 不绑人，天然平权。
6. **环合处理**：以公网根为锚的树——每个节点朝根方向单一上游；多宿主 = 多身份多路径；
   同身份重复接入拒绝（配合域内身份，P2）。
7. **链接即配置（`anet://` 统一格式与解析器）**：一切需要手工填的技术字段（地址/token/SNI/指纹）都必须能
   打包进一条链接，所有相关表单同时是解析器——粘贴即导入，表单只剩业务字段。scheme 用 `anet://`
   （`agilenet://` 过长；解析器必须兼容旧 scheme 做平滑迁移）。扇出链接承载：入口地址:端口 +
   psk_ token + SNI + 证书指纹（+ 可选 expose 控制面标记），与账号 connect_url 同一套解析底座。
   链接含凭证，等同密码对待（分享渠道自律；一次性 ticket 变体留作后续）。
8. **`.anet` 文件载体（链接的文件形态）**：同一载荷可导出为 `xxx.anet` 文件导入（文件选择 / 双击关联 /
   拖拽进 GUI 三入口）。容器格式：magic `ANET1` + 版本 + JSON 信封（role、技术字段、签发者、签发时间、
   用途备注——导入对话框先展示元信息再确认应用）。加密复用设置同步的既有机制（sync.rs：版本化
   AES-256-GCM，4 位 PIN 或明文，导出时默认推荐 PIN）。
   安全定位要诚实：PIN 加密挡的是** casual 泄露**——IM 平台对 URL 的爬取/预览/关键词扫描、聊天记录
   搜索、剪贴板管理器、日志采集器，文件形态天然免疫（平台不爬文件内容）；不挡拿到文件后定向爆破
   （4 位 PIN 离线可穷举），PIN 与文件必须分渠道传输才有意义。企业价值同时在于正式感：
   命名建议 `<签发方>-<用途>-<日期>.anet`，配合 §2.7 协议注册形成「链接（即时）/ 文件（归档流转）/
   二维码（现场，已有）」三载体。

## 3. 现有地基（勿重复造）

- 路由收敛与再发布（advertise + route re-publish，Docker 四级链断言）——传递可达已实现；
- 扇出侧执法钩子 `relay::PeerAcl`（docs/todo/peer-acl.md）——C 本地按组执法的挂点已存在；
- handshake v2 relay ticket + manageable registry（管理可达自动发现）——域内身份的雏形；
- connector 证书指纹钉值（DB v8+，2026-08-04 落地）——免 insecure 的对端验证；
- `node_config.public_host` 热生效（2026-08-04 落地）——链接对外地址即时可配；
- relay_token 已支持 scope/权限组收敛（B 对扇入侧的收敛）。

## 4. 分期实施

### P1 — Rendezvous 链接与策略上送（管理面，无新加密）✅ 已落地（2026-08-04）

- ✅ 下游扇出注册时，其 advertise 路由自动汇入上游的**可授权池**（带来源 tag = 节点身份，解决命名冲突）
  —— `RelayListener::peer_offers()` + `GET /api/v1/admin/federation/offered`；
- ✅ 权限组对象（组 + 规则）可随扇出推送上游，来源 tag 标记；上游控制台开账号时直接引用「C 的 xx 组」
  —— `AuthRequest.groups`（serde 兼容旧上游）+ connector `push_groups`（DB v9）+ 扇入页端点行展开 +
  `POST /api/v1/admin/federation/adopt` 一键物化（组名 `组名@节点ID`，规则按 (type,value) 复用）；
- ✅ 签发链接时可选端点：**经上游中继**（入口=对外地址）或**同内网直连**（内网 IPv4 枚举）
  —— 签发弹窗统一为「分享卡片」（端点切换 + 完整链接/仅密钥 tab + 下载 .anet）；
- ✅ **公网身份产品化**：`anet init` 向导新增「本机是否公网会合点 + 对外地址」落 `public_host`；
  管理端设置页公网地址预填 + ahelp（GUI 扇出监听面板此前已落地）；
- ✅ **反代/域名场景**：`node_config.public_api_url`（scheme://host[:port]，settings 热生效）——
  接入链接携带 https scheme；relay 数据面 L4 透传约束写入 ahelp 与 wiki；
- ✅ **扇入令牌分享链接化**：relay token 创建响应含 `share_url` + `endpoints`，分享卡片 tab 二选一复制
  （完整链接 / 仅密钥）；地址来源优先级：对外声明（public_host）> 本机监听地址；
- ✅ **扇出粘贴导入**：管理端与桌面端扇出表单顶部粘贴条，anet://fanout 粘贴即填充全部技术字段，
  人工只剩 名称 | 额外路由 | 权限组 | 上送组 | 备注；解析失败回退手工模式并给出错误行；
- ✅ **`anet://` 系统协议注册**：桌面注册 anet/agilenet scheme（tauri-plugin-deep-link + single-instance
  argv 转发），Android intent（scheme+host connect/fanout）；前端按链接角色自动落到扇入导入 / 扇出表单；
  解析底座 `core::link`（Rust）+ 共享 `aglink.js`（双端表单），兼容旧 `agilenet://`；
- ✅ **`.anet` 文件导出/导入**：签发处（扇入令牌、账号、扇入列表导出）提供「下载 .anet」；
  信封 magic `ANET1` + role + 签发者 + 时间 + 用途备注；PIN 加密与设置同步同构（PBKDF2-100k +
  AES-256-GCM，WebCrypto 共享 `aganet.js`，默认推荐 PIN）；导入三入口（文件选择 / 拖拽入窗 /
  双击文件关联 tauri fileAssociations），导入对话框先展示信封元信息再确认应用；
- 验收：拓扑 §1 中 C 在 B 上不触账号的前提下，让 B 管理员一键把「C 的 git 组」授权给 A
  —— **e2e 覆盖：`crates/node/tests/federation_test.rs`（push → 池化 → adopt → 授权 A → ACL 含 C 的目标）**。

### P2 — 域内身份与签发委托

> **实施设计已定稿：`docs/plan/federation-p2p3.md`**（2026-08-04）。关键演化：**以「会话内注册 +
> 生命周期随会话」替代迷你 CA 与吊销传播**（注册通道即信任通道；C 离线时 A 本就不可达 C 资源，
> 会话级生命周期语义自洽，吊销即断天然成立）；域内身份 = node_id + token 哈希，同身份踢旧留新。
> 多入口 v1 为单入口选择（多入口链接留延伸）。以下为原始讨论要点，实施以计划文档为准：

- 根为下游节点身份背书（迷你 CA：根签节点证书，扇入方验链）；同身份重复接入拒绝（环合防线）；
- C 签发的 psk_ 令牌经扇出会话注册到 B，B 验签代收；吊销沿链传播；
- **多上游入口选择**：资源主的网关（M）多宿主扇出 B1/B2/B3 时，路由已全量同步到各 B（现状即如此），
  签发时按扇出会话**选择入口 B**（就近/成本/隔离/负载），令牌只注册到所选 B，链接入口地址随之；
  延伸项：**多入口链接**（同一令牌注册多 B，链接带入口列表，客户端测速选择/失败切换）解决单 B 失效脆性；
  信任含义：透明档下选 B = 选「让谁看见流量」，E2E 档下选 B 仅是可用性/成本决策；
- mux 会话握手携带**组标识**，C 侧 PeerAcl 按组执法（会话级，替换现在的 connector 级整体收敛）；
- 验收：C 本地签令牌 → 发链接给 A（地址=B）→ A 扇入 B 自动路由至 C，C 按组放行；C 吊销即断。

### P3 — E2E 载荷加密（不信任档）

> **实施设计已定稿：`docs/plan/federation-p2p3.md`**。关键演化：**v1 密钥 = HKDF(令牌明文)**
> （零握手，B 只有哈希推不出；Noise_NK 带 FS 留 P3.5）；**hint_map 路由词表**由注册帧携带——
> B 只见粗 hint，真实目标进 AEAD blob，R1 场景由此闭环。以下为原始讨论要点，实施以计划文档为准：

- 客户端 ↔ 出口节点 Noise/WireGuard 式握手（密钥经 ticket/接入链接交换），mux 帧载荷密文化；
- 资源主按权限组选择强制 E2E；B 对 E2E 会话仅见路由标签；
- 配套：粗广告 + 本地细授权（§2.4 的 R1 场景）；
- 验收：B 上抓包只见目标节点标签；C 未推送的规则 R1，A 经授权可达、B 全程无感知。

### P4 —（可选远期）NAT 穿透

无公网节点互连且不愿经根中继时：打洞 / 中继分配。非本计划必需项。

## 5. 非目标（Non-goals）

- 接入链接编码路径（源路由）——见 §2.1；
- 按节点分配 TCP 端口——见 §2.2；
- 全网状自动互连（无根对等发现）——本模型以公网根为锚；
- 匿名性（Tor 目标）——本模型目标是主权与可达，不是隐身份。

## 6. 今天 vs 终态对照（标尺拓扑）

| 能力 | 今天 | 终态 |
|------|------|------|
| C 直接签发账号给 A | 不能（须 B 管理员开账号） | 能（P2 签发委托） |
| A 抵达 C/D 深层集群 | 能（路由收敛，已实现） | 能（不变） |
| 按 C 的权限组粒度授权 A | **能（P1 策略上送 + 一键采纳，已落地）**；C 侧热更随重连再上送 | 能（P2 会话组标识更细） |
| B 看不见 C 的内容与细规则 | 不能（逐跳 TLS） | 能（P3 E2E + 粗广告） |
| 同内网直连分享 | **能（P1 签发端点二选一，已落地）** | 能（不变） |
| 多公网上游入口选择 | 路由已同步各 B，账号按 B 手工割裂 | 签发时按扇出会话选 B，可多入口容灾（P2） |
| 公网身份/域名反代 | **能（P1：init 向导 + 控制台公网身份 + public_api_url 反代端点，已落地）** | 不变 |
| 扇入令牌分享 | **能（P1：一键链接 tab 复制，扇出粘贴即导入只剩业务字段，已落地）** | 不变 |
| 链接拉起应用 | **能（P1：anet:// 桌面/Android 协议注册，浏览器地址栏可拉起自动导入，已落地）** | 不变 |
| 凭证流转载体 | **三载体齐备（P1：链接 / 二维码 / .anet 文件 PIN 加密可选，已落地）** | 不变 |

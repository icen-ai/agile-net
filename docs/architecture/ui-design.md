# Client UI 设计

Tauri + React，系统托盘常驻，轻量级。

## 页面结构

```
AgileNet Client
├── 系统托盘图标
│   ├── 右键菜单：显示主窗口 / 全部连接 / 全部断开 / 退出
│   └── 图标状态：灰色(未连接) / 绿色(已连接) / 黄色(部分连接)
└── 主窗口
    ├── 侧边栏（极简）
    │   ├── 连接     — 节点管理
    │   ├── 状态     — 实时流量
    │   └── 设置     — 偏好
    └── 内容区
```

```
│  连接                          [+ 添加节点] │

```

### 添加节点方式

1. **扫码** — 扫 Admin 生成的二维码（`agilenet://` URL）
2. **手动** — 填写服务器地址、端口、账号、密码
3. **粘贴链接** — 粘贴 `agilenet://connect?...` URL

## Tauri IPC Commands

```rust
// 节点连接管理
#[tauri::command]
async fn add_node(info: NodeConnectInfo) -> Result<NodeId>;

#[tauri::command]
async fn remove_node(id: NodeId) -> Result<()>;

#[tauri::command]
async fn connect_node(id: NodeId) -> Result<()>;

#[tauri::command]
async fn disconnect_node(id: NodeId) -> Result<()>;

// 状态查询
#[tauri::command]
async fn get_status() -> Result<ClientStatus>;

#[tauri::command]
async fn get_active_routes() -> Result<Vec<RouteEntry>>;

#[tauri::command]
async fn get_connections() -> Result<Vec<ActiveConnection>>;

// 设置
#[tauri::command]
async fn get_settings() -> Result<ClientSettings>;

#[tauri::command]
async fn update_settings(settings: ClientSettings) -> Result<()>;

// hosts
#[tauri::command]
async fn get_hosts_entries() -> Result<Vec<HostEntry>>;
```

# AgileNet 里程碑计划总览

## 原则

- 每个里程碑有**可观测、可验收**的产出
- 每个里程碑定义**验收测试**，开发必须同步编写
- 后续里程碑的回归测试必须覆盖前序里程碑的核心功能
- 里程碑之间不跳跃，前一个验收通过才开始下一个

## 回归规则

每个里程碑的 CI 必须通过**本里程碑 + 所有前序里程碑**的全部验收测试。M8 是全量回归门禁。

## 依赖关系

```
M1 → M2 → M3 → M4
              ↘
M1 ─────────→ M5 → M6 → M6.5
                  ↘       ↘
M4 + M5 ─────────────────→ M7 → M8
```

M2/M3 可并行开发（不同 crate），M4 是集成点。M5 可以在 M3 之后开始（API 不依赖完整隧道）。M6.5 在 M6 之后补充纯终端 TUI 支持。M7 需要 M4（端到端）和 M5（API）都完成。

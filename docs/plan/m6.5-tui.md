# M6.5：Node TUI 终端界面 (Terminal User Interface)

## 目标

为 `agile-net-node` 增加纯终端无图形化界面的交互控制台 (TUI)。在开发者仅能通过 SSH (22 端口) 登录纯终端服务器、Web 端口被防火墙封锁无暴露环境时，提供交互式节点监控、路由规则配置与监控能力。

## 依赖

M5 / M6 完成（内部 API / 数据库和路由模型全部就绪）。

## 产出

1. 纯 Rust TUI 终端组件 (`ratatui` + `crossterm`)
2. `agile-net-node tui` 命令行交互子命令入口
3. 支持实时节点在线状态、路由表管理与交互式登录

## 技术选型

| 库 | 用途 |
|----|------|
| `ratatui` (v0.29) | 终端界面渲染与布局框架 |
| `crossterm` (v0.28) | 跨平台终端事件捕获 (键盘输入、Resize) |


## 验收测试

### AT-M6.5-01：TUI 运行状态初始化与干净退出

```rust
#[tokio::test]
async fn tui_app_state_initialization() {
    let db = Database::in_memory().unwrap();
    let app_state = TuiApp::new(db);
    assert_eq!(app_state.current_tab, Tab::Overview);
    assert!(!app_state.should_quit);
}
```

### AT-M6.5-02：TUI 按键事件路由处理

```rust
#[tokio::test]
async fn tui_key_event_handling() {
    let db = Database::in_memory().unwrap();
    let mut app = TuiApp::new(db);
    
    // 模拟按下 'q' 触发退出
    app.handle_key(KeyCode::Char('q'));
    assert!(app.should_quit);
}
```

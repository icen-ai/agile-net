# M6.6：CLI 命令行工具 (anet)

## 目标

为 AgileNet 构筑轻量、高效、面向运维与自动化脚本的统一命令行工具 `anet`。支持系统状态查看、登录凭证管理、节点管理、路由规则 CRUD，以及直接调起 TUI 界面或 Node 守护进程。

## 依赖

M5（REST API 与数据库模型）、M6.5（TUI 终端控制台）。

## 产出

1. 独立可执行二进制 `anet`（基于 `crates/cli` 构建）
2. 完整命令行解析与子命令架构（基于 `clap` 4.x derive 模式）
3. 交互式 REST API Client / 数据库回退兼容层
4. 完整的单元与集成测试套件 (`AT-M6.6-01` ~ `AT-M6.6-04`)

## CLI 指令规范 (`anet`)

```bash
anet --version                   # 输出版本信息
anet status                      # 查询当前 Node 运行状态与系统信息
anet login                       # 登录并保存 JWT Token 至本地配置
anet node list                   # 查看已注册的 Node/Peer 列表
anet route list                  # 查看当前所有代理路由规则
anet route add --pattern <P> --type <T> --outbound <O> [--node-id <N>] # 新增路由规则
anet route delete <ID>           # 删除指定 ID 的路由规则
anet tui                         # 启动 TUI 交互控制台
```

```rust
#[test]

    let mut cmd = assert_cmd::Command::cargo_bin("anet").unwrap();
    cmd.arg("--version").assert().success().stdout(predicates::str::contains("anet 0.1.0"));
}
```

### AT-M6.6-02：CLI 路由规则子命令解析

```rust
#[test]
fn cli_route_add_arg_parsing() {
    let cli = Cli::parse_from(&["anet", "route", "add", "--pattern", "10.0.0.0/8", "--type", "cidr", "--outbound", "direct"]);
    match cli.command {
        Commands::Route(RouteArgs { command: RouteSubcommand::Add(add_args) }) => {
            assert_eq!(add_args.pattern, "10.0.0.0/8");
            assert_eq!(add_args.pattern_type, "cidr");
            assert_eq!(add_args.outbound, "direct");
        }
        _ => panic!("Expected Route Add subcommand"),
    }
}
```

# AgileNet 商业思考与演进 (一)：卖点研究与付费逻辑

本文档记录了关于 AgileNet 早期商业化方向、产品形态以及收费逻辑的核心推演。

## 1. 为什么 AgileNet 有市场？（生态断层分析）

AgileNet 的核心价值在于缝合了市场上三个互不交集的阵营的优点，填补了“私有化部署 + 极简前端体验 + 高级路由规则”的生态空白：

1. **补足“开源极客派”（如 frp, nps）的最后一公里**：开源工具通常只有 CLI，配置繁琐（如 `frp.ini`），缺乏可视化面板，将无技术背景的终端用户拒之门外。AgileNet 提供了高颜值的 GUI 和简单的交互。
2. **打破“资本 SaaS 巨头”（如 Tailscale）的控制权**：SaaS 巨头强制节点接入官方控制平面并按人头收取高昂订阅费。AgileNet 采用“BYOI (Bring Your Own Infrastructure) 买断/授权”模式，数据完全自主可控。
3. **合法化与双向化“代理工具派”（如 Clash 衍生版）的能力**：传统代理工具侧重于“单向扇出（科学）”，而 AgileNet 将“高级路由分流”与“双向内网穿透/组网”结合，打造合规的阳光化企业级网络工具。

**核心结论**：“把复杂的东西做简单”、提供优秀的整合体验和跨平台工程化能力，本身就是巨大的商业护城河。

## 2. “特洛伊木马”增长策略：用高频工具打低频场景

完全依靠“内网穿透”这一相对低频的需求难以获取大量 C 端装机量。AgileNet 的核心获客策略是 **PLG (Product-Led Growth)**：

*   **瘦客户端，永远免费**：`anet-gui` 客户端完全免费，不限制下载，不限制当做本地代理工具使用（支持订阅导入、分流规则、流量统计）。
*   **跨界平替**：凭借高颜值仪表盘和直观的路由配置，AgileNet GUI 足以作为优秀的本地网络规则管理器，替代市面上体验不佳或价格昂贵的代理客户端。
*   **无痛转化**：当用户习惯将 `anet-gui` 作为系统常驻工具后，一旦产生“穿透/组网”的刚需，只需在软件内一键扫码激活（例如 19元/月），即可无缝解锁专有 Relay 和内网互联功能。

## 3. 付费逻辑推演：如何防止被“白嫖”？

在允许客户端免费下载的前提下，如果不做精细的限制，大企业只需购买最便宜的个人套餐，就能让全公司员工接入同一个 Relay，导致商业价值流失。

解决这个“汇聚白嫖漏洞”的原则是：**不限制终端下载数量，但限制单节点的并发/带机量，并对高级互联功能收费。**

### 3.1 基础套餐区分：限制“扇入”能力

免费版仅提供**纯客户端（终端）体验**，能够连向付费用户的 Relay，但**禁止自身成为 Relay（禁止扇入）**。
*   这样既保证了体验的完整性（能用），又掐断了免费用户通过“无限级联”白嫖网络的可能。
*   免费用户越多，对付费中继节点的需求就越大，倒逼具备服务能力的用户付费。

### 3.2 商业版图与定价模型设想

采用**“非对称定价（胖服务器，瘦客户端）”**与**“并发数（带机量）限制”**相结合的模型：

| 特性 / 版本 | 免费版 | 专业版 (例: ¥19/月) | 团队版 (例: ¥99/月) |
| :--- | :--- | :--- | :--- |
| **核心定位** | 纯客户端，体验引流 | 个人、小微团队工作室 | 中小企业、重度网络联邦 |
| **客户端 GUI** | 永远免费，无限下载 | 永远免费，无限下载 | 永远免费，无限下载 |
| **Relay 节点授权** | 0 个 | ≤ 10 个节点 | ≤ 50 个节点 |
| **扇入 (Relay) 能力** | ✗ (仅限扇出直连) | ✓ (可作为 Relay 接收连接) | ✓ (可作为 Relay) |
| **单点带机量限制** | - | **例如：限 20 人并发** | **例如：限 200 人并发** |
| **企业联邦对接** | ✗ | ✗ | ✓ (**Site-to-Site 互联凭证**) |

### 3.3 企业级联邦对接（Site-to-Site）商业壁垒

当 A 公司的 Relay 节点想要将 B 公司的 Relay 节点设为上游网关时，B 公司不能提供普通的客户端链接。
*   **高级能力变现**：这种“节点连节点”的互联需求属于极高价值的企业功能。
*   **门槛与限制**：生成此类“联邦对接凭证”必须是高级套餐（如团队版）专属功能。同时，在生成凭证时可以细粒度地设置**带宽上限、并发上限和内网 IP 白名单**，彻底防止 B 公司的高配资源被 A 公司榨干白嫖。
